DUCK QUILL
Draw, paint and animate, with a pen or with a script.


TO START
  Installed with DuckQuill-<version>-setup.exe: Duck Quill is in the
  Start menu, and double-clicking a .quill picture opens it.

  From the zip (the portable copy): double-click DuckQuill.exe. For a
  desktop icon, double-click "Create desktop shortcut.bat", and keep
  this folder where it is afterwards: the shortcut points into it.

  The first time, Windows may say "Windows protected your PC". That's
  because the program isn't signed with a (paid) certificate yet, not
  because something is wrong. Click "More info", then "Run anyway".
  Windows only asks once.

  Duck Quill opens on its Home page: new pictures, your recent ones,
  and any unsaved work from last time. Ctrl+K finds any command by name.


WITH A PEN TABLET
  Duck Quill reads pressure and tilt through Windows Ink. If your
  tablet's driver (Wacom, XP-Pen, Huion...) has a "Use Windows Ink"
  option, keep it switched on. The "Pen test" screen in the top bar shows
  what your pen sends.


WHAT'S IN THIS FOLDER
  DuckQuill.exe    the app
  quill.exe        Duck Quill on the command line: paints scripts into
                   pictures without a window (for AI agents, or for you)
  art-cli.exe      quill's old name, for scripts written before the rename
  skills\          what an AI agent reads to paint with quill
                   (start with skills\duck-quill\SKILL.md)
  brand\           the Duck Quill icon


DRAWING AN ANIMATION
  View > Animation tools turns on the timeline at the bottom (and off
  again: nothing you drew is lost). File > New animation starts one: a
  Background layer that's the same on every frame, and a Drawing layer
  with a drawing per frame. Keys: , and . go back and forward a frame,
  / plays. Tick "Onion skin" to see the frames before (red) and after
  (blue). File > New pixel sprite or tile starts a small sprite with the
  Pixel pencil. File > Export animation saves a GIF or a sprite sheet.


A NEW VERSION
  Installed: Duck Quill says when a new version is out ("Update" at the
  top). One click downloads it, checks it's exactly the file that was
  published, and installs it; Duck Quill opens again with your picture.
  If anything goes wrong, the version you had is put back. Help > Check
  for updates asks straight away. (It only asks GitHub for the newest
  version's number: nothing about you or your pictures is sent.)

  Portable copy: "Download" opens the Releases page. Download the new
  zip, unzip it, and replace this folder with it.

  Moving from 0.5.0 (which has no updater): run the setup once, then
  delete the old unzipped folder and its desktop shortcut. Your
  settings, presets and recent pictures carry over.

  Your pictures are wherever you saved them, never in the program's
  folder, so they are safe either way. Uninstalling (Windows Settings >
  Apps) never deletes them, or your settings.


Pictures made with Art App (the old name, .artapp files) open in Duck
Quill as they are.
